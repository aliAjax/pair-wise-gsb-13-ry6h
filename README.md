# 加油站班次交接 · 加油卡预授权

开泵前按 **卡号、油枪、车牌** 冻结额度的前端闭环系统，支持超额补收结算、调整版本化、未结授权跨班交接，以及重开后的一致性自检。数据保存在浏览器 localStorage。

- 技术栈：Vue 3 + Vite + TypeScript + Pinia + Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`（含 `tsc -b` 严格类型检查）

## 业务规则

### 开泵预授权
- 录入卡号、油枪、车牌、冻结额度，校验通过后冻结额度并开泵。
- 拒绝场景（拒绝时**保留已填输入**，仅提示原因）：
  1. 当前无开班；
  2. 卡已挂失；
  3. 录入车牌与卡片绑定车牌不符（车牌做去空格/分隔符、大写规范化）；
  4. 同卡存在未结授权（同卡有未结授权不得再次开泵）；
  5. 油枪正被其他未结授权占用；
  6. 可用余额（账户余额 − 本卡未结冻结合计）不足。

### 结算（结清后冻结）
- 结算额 ≤ 预授权额：直接从卡内扣款结清，释放冻结。
- 结算额 > 预授权额：超出部分必须先**补收**（卡外现金/扫码），补收不足不能结清；卡内最多扣预授权额，记录 `补收 + 卡扣 = 结算额`。
- 结清后授权单冻结，不可再结算或调整，仅保留结算记录与版本。

### 调整（带原因另存版本）
- 仅未结授权可调整；原因必填，且内容确有变化才生成新版本。
- 调整不覆盖历史：额度/油枪/车牌/状态整份快照另存，时间线可回溯。

### 班次交接
- 同时只能有一个开班；开班时自动接手处于跨班挂账窗口的未结授权。
- 关班前若有未结授权，必须**逐条填写跨班交接处理办法**，否则禁止关班（处理前不得关班）。
- 关班后未结授权进入挂账窗口（owner 置空），交接历史随单保留；下一班开班即接手。

### 重开一致性自检
重新载入（或点击“重新载入并自检”）时对卡片、授权、班次、版本交叉校验，冲突固定展示 **卡号、油枪、差额、规则**：
- 冻结合计超过卡余额；同卡/同枪多条未结；
- 授权引用的卡号、油枪、班次不存在；
- 已关班仍持有未结授权、同时多个开班、开班未接手挂账；
- 授权无版本、最新版本快照与当前资料漂移；
- 已结清无结算记录、`补收 + 卡扣 ≠ 结算额`。

## 分层结构（资料 / 判定 / 存储 / 页面分开）

```
src/
├─ domain/            授权资料与模型（无逻辑依赖）
│  ├─ types.ts          加油卡、油枪、预授权、班次、版本、冲突类型
│  ├─ seed.ts           演示种子数据
│  └─ money.ts          金额/时间工具
├─ rules/             判定层：纯函数，不碰存储与 DOM
│  ├─ index.ts          开泵/结算/调整/关班规则
│  └─ consistency.ts    重开一致性自检
├─ storage/           存储层：localStorage 读写，卡片/授权/班次/版本分键
│  └─ repository.ts
├─ stores/
│  └─ station.ts        状态编排：串联 rules + storage，供页面调用
└─ views/             页面层：只做交互与展示
   ├─ OpenPumpView.vue    开泵预授权（拒绝保留输入）
   ├─ AuthListView.vue    结算补收 / 调整 / 版本时间线
   ├─ ShiftView.vue       开班 / 跨班交接处理办法 / 关班
   ├─ CardsView.vue       卡片、油枪资料维护
   └─ ConsistencyView.vue 冲突列表（卡号/油枪/差额/规则）
```
